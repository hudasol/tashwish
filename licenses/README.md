`adsblol/globe_history_2026` repository (retrieved 2026-10-12, sha256 `d93f996262c15e7cf9d6b54f9f48e3f9d8b9c3a47fa2308dc8ef1f0f5cb88611`).

(25,278 bytes, sha256 `607680718977f6f6c9607972afd98f208573f19251315ed1362a8589b51beaf5`) was compared line by line with
`ODbL-1.0.txt`. Both have 540 lines. Apart from trailing spaces on some lines of the official copy, they differ in one place:
